# AI Country Music Generator – 页面插图

本目录用于存放与「AI Country Music Generator」页面内容一致的配图，替换原 home 通用图。

## 所需文件（4 张）

| 文件名 | 用途 |
|--------|------|
| `hero-country-music-generator.png` | 首屏主图：乡村/Americana 氛围，吉他、公路或落日感 |
| `country-style-guide.png` | 风格指南区块：Genre/Mood/Ambience 标签、木吉他、灵感感 |
| `country-creators-use-cases.png` | 使用场景：创作者、耳机、工作室/咖啡馆，乡村音乐创作 |
| `country-cta-ready-to-create.png` | 底部 CTA：开放公路/工作室、开始创作的感觉 |

## 建议规格

- 比例：首图与风格/版权区建议 **2:1**，CTA 区建议 **3:1** 横图
- 格式：PNG 或 WebP；若提供 WebP，可另加 `-640` 版本用于 `src640` 以优化移动端
- 风格：暖色、Americana/南方乡村、无大段文字，便于作背景图使用

## 若使用 Cursor 生成的图

若在 Cursor 中已生成上述 4 张图，它们通常在项目下的 `assets/` 目录（或 Cursor 的 assets 输出路径）。将对应文件复制到本目录并确保文件名与上表一致即可。
