# 高清封面（用于 AI 视频生成）

本目录用于存放 **1920×1080** 或更高分辨率的封面图，供 Gemini、ChatGPT 等生成音乐视频时作为参考图或首帧。

## 建议文件名（与 `docs/ai-music-video-generator-scenes.md` 一致）

| 曲目 | 建议文件名 |
|------|------------|
| Cinematic opener | `sample-cinematic-1920x1080.png` |
| Lo-fi focus instrumental | `sample-lofi-1920x1080.png` |
| Loop for talking videos | `sample-loop-1920x1080.png` |
| Documentary emotional bed | `sample-documentary-1920x1080.png` |
| Late night R&B groove | `sample-rnb-1920x1080.png` |
| Game menu ambient | `sample-ambient-1920x1080.png` |

## 规格建议

- **分辨率**：1920×1080（Full HD）或 3840×2160（4K）
- **格式**：PNG（无损）或 JPEG（质量 ≥90）
- **比例**：16:9，便于与视频输出一致

## 来源

- 若有高分辨率原图，可重命名后放入本目录。
- 若仅有上一级目录中的 `sample-*.webp`（约 640px 宽），可先用图像编辑软件或 AI 放大工具生成 1920×1080 再放入此处。

详细情景描述与可直接复制给 AI 的视频提示文案，请见项目根目录下的 **`docs/ai-music-video-generator-scenes.md`**。
