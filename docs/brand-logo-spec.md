# TheAIMusicGenerator 品牌与 LOGO 规范

## 一、品牌名与字标（Wordmark）

- **完整品牌名**：`TheAIMusicGenerator`（对应完整域名与对外名称）。
- **字标设计原则**：在完整名称中，通过 **颜色 + 字重/大小** 突出 **T、A、M、G** 四个字母，其余字母为基底样式。
  - 突出字母：**T**（来自 The）、**A**、**M**（来自 Music）、**G**（来自 Generator）。
  - 基底字母：`he`、`I`、`usic`、`enerator` 使用中性灰或同一字体下的弱化样式。
- **目的**：一眼看到完整品牌名，同时记住 TAMG，便于与 tamg 相关域名统一。

## 二、独立图形符号（Icon）

- **用途**：App 图标、favicon、社交媒体头像、独立露出场景。
- **要求**：可单独使用，不依赖文字；造型与字标有明确关联，便于记忆和行业辨识。
- **当前方案**：**字母 M + 五线谱 + 四分音符**。五根横线（五线谱）贯穿画面，中央为粗体字母 **M**（Music / TAMG），右侧为一只四分音符（符头 + 符干），统一使用亮紫→品红渐变。M 与乐谱、音符结合，兼具品牌记忆与 AI 音乐行业辨识度。

## 三、字标与 Icon 的关联（统一记忆点）

| 关联维度 | 说明 |
|----------|------|
| **配色** | Icon 使用与字标中 T、A、M、G 相同的**主色**（蓝紫→品红渐变），保证同品牌感。 |
| **造型** | Icon 采用**字母 M + 五线谱 + 四分音符**，与「Music」及 TAMG 中的 M 强关联；与字标同屏时统一主色与风格。 |
| **行业辨识** | 五线谱与音符为通用音乐符号，一眼可辨「音乐」行业。 |

使用建议：
- 字标与 Icon 同时出现时（如官网头部、落地页），采用同一套主色与风格。
- 仅使用 Icon 时（如 favicon），用户仍能通过配色与造型联想到完整品牌与 TAMG。
