# 首页配图提示词（照片级 · 与网站匹配）

用于 AI 绘图（Midjourney / DALL·E / Stable Diffusion 等），生成与「AI 音乐生成、创作者、歌词与成曲」相关的**照片级**配图。建议比例与用法见下表；生成时可不写中文，仅用英文提示词。

---

## 通用质量后缀（可加在每条末尾）

- **Midjourney**: `--style raw --v 6` 或 `photorealistic, 8k, professional photography, soft lighting, no text`
- **通用**: `photorealistic, high resolution, professional stock photo, natural lighting, no text or watermark`

## 使用建议

1. **统一风格**：所有提示词已按「照片级、无文字、自然/柔光」写，生成时尽量保持同一 seed 或同一「style」以便整站视觉统一。
2. **人物**：需要时可加 `diverse, inclusive`；避免具体名人或可识别人脸，以免版权问题。
3. **品牌色**：站点主色为紫色（violet），可在 Hero、CTA、How it works 第 2 步等提示词中保留 `purple accent light` 或 `violet glow`，与页面更一致。
4. **尺寸**：导出时按各区块比例（16:9 / 1:1 / 2:1 / 3:1）裁剪，便于直接用作首页配图。
